操作与自动补给

新版手机界面、快捷栏、背包换装与自动补给的图文教程。

手机战斗界面背包与换装物品与技能快捷栏自动补给菜单与全屏电脑操作

手机横屏战斗界面

位置 / 按钮怎么操作
左侧移动区按住移动区拖动摇杆，松手停止；移动时注意人物实际朝向和地形阻挡。
右下角攻击点按攻击当前目标；按住可原地攻击，不追着目标移动。
换目标切换附近可攻击目标；也可以直接点怪物来选择目标。
右下角技能区点已绑定技能施放。第1页是1–4格，第2页是5–8格；方向或地面技能按瞄准提示选择方向/位置。
左侧物品条点已绑定物品立即使用；左右滑动查看全部6格，用旁边设置按钮修改绑定。
任务提示与小地图点任务查看当前目标；点地图入口可打开大地图，结合坐标找NPC、出口与首领。
拾取走近掉落，出现拾取按钮后点按；附近没有可拾物时按钮可能不显示。

背包、装备与左右槽位

  1. 打开背包，先在“装备”和“材料与补给”之间切换，再点物品查看详情。
  2. 装备在详情中点“对比身上”，确认属性变化后点“使用 / 装备”。戒指和手镯要先确认左右对比槽，再替换选中的槽位。
  3. 药品、卷轴等在材料与补给分类中查找。需要频繁使用时，放入物品快捷栏。
  4. 重要装备可锁定，避免误处理。丢弃会移除物品，先确认选中的是哪一件；有些特殊物品不允许丢弃或出售。
  5. 装备和材料各有独立格位，某一分类满了不能只看总剩余数量。整理按钮会合并可堆叠物品并排序。

6格物品与8格技能快捷栏

  1. 点战斗画面的快捷栏设置按钮，或“菜单 → 快捷栏设置”。
  2. 在“物品 · 6槽”中，先点上方目标格，再点下方背包物品完成绑定；清空此槽只移除绑定，不消耗背包物品。
  3. 准备自动补给时，把血药放到第1格、蓝药放到第2格。空格、缺货或药品不符合恢复类型时，辅助不会凭空补药。
  1. 切换到“技能 · 8槽”，选目标格，再选择已学会的主动技能。被动和当前不可施放的技能不占快捷键。
  2. 战斗中单击已经绑定的技能会施法；修改绑定要进入设置，避免边打怪边误操作。
  3. 新角色尚未学习主动技能时，列表为空属于正常情况。先按任务获得技能书、在背包学习，再回到这里设置。

自动血瓶、蓝瓶与自动剑法

  1. 先在物品快捷栏第1格绑定能恢复生命的药品，第2格绑定能恢复魔法的药品，并确认背包仍有库存。
  2. 打开“菜单 → 辅助”，勾选自动血瓶和/或自动蓝瓶。只填写比例、不勾选开关不会启用。
  3. 设置触发比例，范围1%–99%。初始显示生命70%、魔法30%；只有低于设置比例才尝试喝药。
  4. 向下滚动面板，点击“保存设置”，看到保存提示后关闭。设置按角色保存，下次进入仍会保留。
情况对应规则或处理方法
药品没有连续使用普通药正在恢复期间不会重复喝。太阳水和强效太阳水共享4秒冷却，其他瞬回药自动使用间隔至少1秒，还需满足药品使用条件。
血量很低仍不喝依次检查开关是否已保存、第1格是否有恢复生命的药品、库存和冷却；蓝药对应第2格。
默认是否已经开启两个自动喝药开关初始关闭，70%/30%只是默认阈值。
自动烈火 / 自动炙炎学会相应剑法后，冷却完成且魔法足够时自动预备，下一次攻击释放；两者均预备时先炙炎后烈火。死亡或骑乘时暂停。
法师自动魔法法师可开启自动魔法攻击，选择主法术，并按需开启自动魔法盾；设置后点击保存。
是否会自动寻找任务或跨图目标选择、走位和任务仍需玩家操作；辅助不会自动寻找怪物或跨图做任务。
切到其他应用切后台时游戏暂停，不能依靠后台时间持续战斗或补给。

菜单、任务、地图与全屏

入口用途
任务查看当前任务与交付目标，按任务指引寻找NPC或怪物。
地图查看人物坐标和相邻出口；找到入口后再回战斗界面移动。
锻造打开分解、附加精华、手工铸造。查看手工制作教程
辅助设置并保存自动血瓶、蓝瓶与剑法。
原地攻击在菜单中选择原地攻击；新版手机也可长按右下角主攻击键。遇到危险仍需手动走位、换目标。
宠物召回、休息、跟随和指挥目标等操作按角色已拥有的召唤物使用。
全屏浏览器支持时进入全屏横屏。退出后可点“回到全屏横屏”；浏览器不支持时手动横过手机。
切换为电脑操作使用鼠标键盘时可切回电脑界面；手机触控优先使用新版手机界面。
