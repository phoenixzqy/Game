手工制作完整入门

拜师、加工、装备制作、品质与潜能的完整操作路线。

手工入门与拜师材料加工与来源装备制作与配方材料品质与星级潜能洗练与属性天赋石与词缀唤醒凝晶突破与风险

适用于原版中文当前手工系统。按下列步骤准备材料，制作前在游戏内核对品质、星级与费用。

制作图解

对照操作图理解材料组合与制作流程。具体品质和费用可在制作前预览；点击图片放大。

从不会做，到做出第一件装备

  1. 角色达到35级，前往 比奇省 的 比奇匠人（302, 219）。
  2. 准备一份品质≥14的 铜矿，与匠人对话选择“拜师匠人”。交付后开启矿石冶炼、木材加工、宝石加工、布料加工，初始均为1级；装备制造暂未开启。
  3. 点击游戏中的锻造入口 → 手工铸造 → 材料制作，选择铜矿冶炼。先用低价材料积累经验，再逐步解锁铁矿、银矿、金矿。M键是地图快捷键。
  4. 冶炼出一份品质≥25的 金锭，回匠人处选择“交付金锭”。这一步消耗金锭，开启1级装备制造，并给2颗潜能石②。
  5. 准备铜锭×3和2000金币，在“装备制作”选择 铜之护符，核对材料与费用后制作。这个配方每次给2点装备制造经验。
  6. 先确定想做的装备，再找制作书、矿锭、木板、炼化石和布缎。需要星级时再选择高品质材料，不要把高品质存货全部拿去练技能。

品质25金锭怎么做

金矿需要4级矿石冶炼。刚到4级时品质率40%；5级60%；6级80%；7级及以上100%。可以把1至5份金矿合成一个金锭，按总品质计算并向下取整。

当前界面如何操作

1锻造入口2手工铸造3材料制作 / 装备制作4选择配方与材料5核对预览与费用6点击制作

电脑可使用配方旁的材料选择器；手机点击对应选择器。矿石与木材可调整加工份数。制作前看“成品品质 / 星级”预览；选错时先修改材料，不要直接确认。

已有装备参与炼化或制作时会被消耗。自动选料优先低品质材料，锁定的装备不会作为材料；要用高品质材料冲星，请主动核对每一份选择。配方产物标记绑定。

卡住时先检查

情况怎么处理
全部技能0级先到比奇匠人处完成第一步拜师；达到等级还不等于已拜师。
装备制造仍是0级第二步品质≥25金锭还未交付。
材料齐了仍不能做检查具体品名、职业/性别、技能等级、金币、锁定状态和背包空位。
做出了白板护符本来不出星；其他手工看材料总品质，不只看角色等级。
想洗词缀却点了潜能潜能是潜能石生成候选；词缀唤醒用天赋石，是另一个功能。
做之前不知道去哪找材料在材料加工页或装备配方卡片查看每项材料的地图与怪物来源。
