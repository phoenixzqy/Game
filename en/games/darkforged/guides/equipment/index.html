Darkforged Equipment: Affixes, Rolls & Item Levels

Compare Darkforged affixes, weapon and jewellery rolls, and item level versus required level. Learn to filter drops, compare gear and protect favourites.

Updated 2026-11-05

Rarity describes structure; affixes define use

Normal, magic, rare, set and legendary gear have different structures. Magic and rare items roll affixes; legendary items have fixed powers, and sets reward distinct equipped pieces. Wearing a duplicate of the same set piece does not count it twice towards a set bonus.

Item level is not the level needed to equip

Item level affects available affix tiers and socket capacity. Actual required level also considers the native base, rolled affixes, legendary or set definition and inserted runes. Use the required level shown in item details rather than treating item level as the equip requirement.

Reduced requirement belongs to this item

The reduced-level property applies after this item’s original requirement is calculated, with a minimum requirement of level 1. It does not lower the requirements of other equipment or the whole character, and does not remove class, gender or other native restrictions.

Filter before comparing

Open equipment management from the workshop or recipe book to view bag, equipped or stored items and filter by rarity, slot, usability, favourites, names and properties. It does not rearrange bag slots. Stored items support a read-only comparison; take them back into the bag when the game requires it before equipping.

Favourite before an intentional spend

Favourites guard against active mistakes such as selling, dropping, salvaging and automatic material selection for ordinary recipes. Upgrading, reforging, enchanting and socketing remain explicit changes and keep the favourite flag. Favouriting does not change death rules or guarantee that an item can never be lost.

Primary attribute tiers and real affixes

Primary attributes: weapons and jewellery

Attack, magic and Taoist affixes use only the highest tier unlocked by item level. Weapons and jewellery have different ranges. +N below is an attribute bonus, not the final item stat.

Item level comes from the defeated monster, with +2 for elites and +4 for bosses, capped at 99. It is not character level or required equip level.

Probabilities assume that the matching primary affix has already rolled on this slot. They are not chances per item drop or monster kill. Rarity rates, affix counts, selection weights, eligible slots and class rules remain unchanged.

Legendary and set item attributes

Existing fixed primary attributes roll within each item identity’s own range using the same distribution. Item level does not turn a low-tier identity into a higher one. Pieces without that primary attribute do not gain it, and the same attribute cannot roll again as a random affix. Chances below assume this identity and its fixed property have already been selected.

New rolls and existing equipment

Newly generated primary attributes and new primary affixes from intentional enchanting or rare-item reforging use the current rules. Existing saved affix values, fixed attributes and equip requirements are not recalculated. Enchanting changes only the selected affix, never a legendary fixed attribute. Bases, normal gear, set-count bonuses, runes and runewords retain their own rules.

New items still use the existing equip-level formula, then this item’s requirement reduction. Do not treat the item levels below as equip requirements.

These ranges come from the current affix tiers. They describe possible rolls, not a promise about your next drop or enchant.
