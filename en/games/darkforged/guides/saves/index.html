Saves: local progress, backups and separate cloud storage

Darkforged characters, equipment, bags, quests, favourites and progress belong only to this game. Continue through the Darkforged play link and use this game’s own save, backup and restore controls.

Updated 2026-11-05

Reading routeConfirm the local save before leavingA backup belongs to DarkforgedCheck the target before restoringCurrent cloud-save statusBefore changing browsers or clearing site data

Confirm the local save before leaving

Use Save in the system menu and wait for success before closing the game or page. Local progress lives in this browser’s site data. Return through Darkforged to continue this game’s character.

A backup belongs to Darkforged

Use Darkforged save management and export when you need a copy, and label it with the game and date. Import only a file exported by this game. Do not import Classic or another game’s backup, or transfer items, characters or progress to another game.

Check the target before restoring

In Darkforged save management, check the character, date and local progress before confirming a restore. A backup restores this game. Check the in-game preview and final confirmation to understand what happens to existing characters. Keep a copy of the current Darkforged progress when unsure.

Current cloud-save status

Use this game’s dedicated cloud panel when its service is available, after signing in with the website account. Game sign-in enables automatic cloud sync, which you can turn off in-game. Resolve character differences when prompted and wait for confirmed sync. Even with the same account, only Darkforged saves are read or written. Other games are never read, converted or overwritten.

Before changing browsers or clearing site data

Browsers do not automatically share local progress. Before clearing site data, confirm this game’s backup or an explicit result from enabled cloud sync. Signing in or selecting another game does not by itself restore a character.

This page explains the save boundary. It does not read, upload or modify a player save. Use the save result and restore confirmation shown inside the game.
