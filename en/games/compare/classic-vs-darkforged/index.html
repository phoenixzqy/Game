Classic vs Darkforged: Choose Your Adventure

Choose according to what you want to pursue. Classic is a good starting point for familiar map routes and target items. Try Darkforged if you enjoy judging random drops and combining equipment effects.

Main pursuit

BackMir Classic

Develop a character through maps and quests; hunt Classic target items.

Darkforged

Build around random affixes, legendary powers, sets and runewords.

Judging equipment

BackMir Classic

Check native stats, exceptional properties, class and existing set rules.

Darkforged

Consider the base, item level, rarity, individual affixes, required level and combined effects.

Crafting

BackMir Classic

Use the existing Classic crafting and Pandora recipes.

Darkforged

Keep available native recipes, plus essence salvage, one-affix enchanting, socketing and Darkforged cube operations.

Runewords

BackMir Classic

Does not use the Darkforged runeword system.

Darkforged

Requires a normal base with the right type, exact sockets and rune order.

Characters and saves

BackMir Classic

Uses Classic characters and its own save system.

Darkforged

Separate characters, browser saves and dedicated cloud storage; no imports or overwrites across games.

Best fit

BackMir Classic

Map exploration, target drops and steady accumulation.

Darkforged

Equipment choices, base planning and experiments with builds.

View in-game screenshots of both games

Understand the save boundary first

You can try both games, but they do not share bags, characters or item exchange. Numbers from a Classic guide must not be treated as Darkforged equipment rules.

Local characters save separately. Game sign-in enables automatic cloud sync, which you can turn off in-game. Confirm successful sync in this game’s cloud panel. Keep this game’s copy before clearing site data.
